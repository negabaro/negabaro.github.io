vscode에서 작업중인 파일을 커맨드로 크롬 브라우저에서 열기

July 7, 2019 · 1 min read vscode

cmmand+shift+P -> Configure Task입력 -> others선택해서 tasks.json을 열기

-> tasks.json을 이하내용으로 수정하고 저장

{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "open",
            "type": "shell",
            "command": "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome",
            "args": [
                "${file}"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            }
        }
    ]
}

-> 브라우저에서 열고 싶은 파일을 탭에서 선택하고 cmd+shift+B -> 해당 파일이 브라우저에서 열리면 성공!
